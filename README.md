# thaana
A set of beautifully designed [shadcn](https://github.com/shadcn-ui/ui) components that you can customize, extend, and build on.

# Documentation

Visit https://thaana.yazak.me to view the documentation.

Licensed under the MIT license.

The source registry is defined by `registry.json`. Generated static item payloads are written to `public/r` by the shadcn CLI.
